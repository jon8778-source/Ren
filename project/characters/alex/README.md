# Alex — proposed pose set

Status: PROPOSED. Generated by Muse on 24 November 2026 from the approved
coffee-v3 prototype artwork of Alex (`alex-cafe.png`, SHA-256
83d61936e45f62b7eef7ec253f1b4a3bce3661117afe96c13ae66009029f943b, in
`project/prototypes/coffee-minute-v3/artwork/`). The owner reviewed the
presenting, neutral, thinking, thumbs-up and pointing poses in chat, approved
the refined design (smaller eyes, full feet in frame), and approved generation
of the remaining poses (waving, worried, shocked) on 24 November 2026.

This set is NOT yet approved for production use. It is a candidate reusable
character set for Alex, who previously had only episodic prototype artwork.
Formal asset approval and a registry status change in
`project/assets/APPROVED_ASSET_REGISTRY.md` are still required before any
episode use.

## Files

Each pose PNG is stored as base64 chunks, following the coffee-v3 prototype
convention: `artwork/<pose>.png.b64.000`, `.001`, ...

Restore a pose with:

    cat artwork/alex_neutral.png.b64.* | base64 -d > alex_neutral.png

Verify against the SHA-256 in `manifest.json` after restoring.

## Poses

presenting, neutral, thinking, thumbs_up, pointing_right, waving, worried,
shocked. All full-body, plain cream background, mouths closed except the
expressive thumbs_up (open smile), worried (tense) and shocked (small o)
stills. Pointing pose points and looks toward screen-right.
