# Ren Long 1: Open Enrollment — production handover

Prepared 6 November 2026.

This bundle contains a **revised candidate full narration script**, **Claude Code prompt**, **fact-check assumptions**, **reusable image/graphic storyboards** and **thumbnail concept**. The visual comps use the user's supplied reference artwork and are NOT a new set of owner-approved v3 assets. For the real animation, Claude Code must source the verified original artwork and renderer from GitHub. New Dev/Priya character portraits have **not** been invented: use off-screen messages or seek a separate art approval gate.

Start with `docs/CLAUDE_CODE_PROMPT.md`. Its first deliverable is a complete 60-second pilot; it must STOP for approval before producing a full episode. This bundle does not produce or request either of the two Shorts.

Asset graphics are deliberately coded as editable overlaid typography instead of baking numerical claims into generative character art. Use the layout references to rebuild motion graphics within the approved Ren renderer, rather than cutting these PNGs directly into final shots.
