## hook
[h01] One Tuesday, the same envelope lands in five mailboxes. {=5}
[h02] Inside is a surprise dental bill for one thousand two hundred dollars. {bill}
[h03] Same bill, same month, but five very different paychecks. {=5}
[h04] Sam takes home two thousand four hundred dollars a month. {sam.income}
[h05] Richard takes home twenty-two thousand. {richard.income}
[h06] So Richard handles it best, right?
[h07] Not so fast. Income isn't what decides who stays calm this month.
[h08] Something else does, and by the end, you'll spot it in your own budget.
